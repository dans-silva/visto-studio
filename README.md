# Visto Studio — site de portfólio

Site estático (HTML, CSS e JS num único `index.html`, vídeos e imagens em `media/`).

## Como adicionar ou trocar um trabalho
1. Coloque os arquivos em `media/` com o mesmo nome: `meu-video.mp4`, `meu-video.jpg` (capa) e `meu-video-previa.mp4` (trecho curto sem som).
2. No `index.html`, procure por `CONTEÚDO DO SITE` e adicione um bloco na lista `trabalhos`.
3. Faça o commit e o push. O GitHub Pages atualiza o site em 1 ou 2 minutos.
